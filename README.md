# Global Electronics Retail Sales & Customer Analytics

## Project Overview
An end-to-end data analytics project using Python, Pandas, and Power BI to analyze retail sales performance.

## Tools Used
- Python
- Pandas
- Power BI
- MySQL
- Excel/CSV

## Analysis Performed
- Data cleaning and preprocessing
- Revenue and cost analysis
- Profit analysis
- Category-wise sales analysis
- Product performance analysis
- Monthly revenue trends
- KPI analysis

## Power BI Dashboard
The dashboard includes:
- Total Revenue
- Total Profit
- Total Quantity
- Total Orders
- Revenue by Category
- Revenue Trend
- Top 5 Products by Revenue
- Profit by Category
- Category Filter

## Dataset
Global Electronics Retailer dataset from Maven Analytics.

## Project Outcome
Created an interactive Power BI dashboard to understand sales performance and identify important business trends.
